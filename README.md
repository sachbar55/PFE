# Plateforme de Gestion d'Assurance Automobile - PFE

Plateforme digitale intégrée pour AtlantaSanad Assurance couvrant le cycle complet de l'assurance automobile avec module de détection de fraude basé sur ML.

## Modules
- Souscription & Gestion Contrats
- Gestion Clients (CRM)
- Gestion Sinistres
- Détection Fraude (IA)
- Portail Client (Web/Mobile)
- Administration & Reporting

## Configuration du Projet

### Prérequis
- Node.js 18+
- PostgreSQL 14+
- Redis 7+
- Docker & Docker Compose

### Installation
```bash
npm install
npm run setup
```
